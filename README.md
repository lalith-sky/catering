## 🍽️ Initial Menu Packages
- **Basic Veg Menu (₹250 / plate):** Focused traditional feast with 1 sweet, flavoured rice, customer choice of 1 curry category (Wet OR Veg curry), white rice, fry, dal, sambar, rasam, snacks, chutney, pickle, papad, curd, pure ghee, and mouth freshener.
- **Regular Veg Menu (₹310 / plate):** Grand celebration feast with 1 sweet, flavoured rice, both Wet and Vegetable curries, rotis, fresh salad, pickles, snacks, and all traditional accompaniments.

## 🚀 Key Features
- **Interactive Guest Count & Indicative Cost Calculator** with presets (50, 100, 200, 300, 500 guests).
- **Online Booking Enquiry Form** with real-time total estimation, field validations, reference code generator, and celebration confetti.
- **Instant WhatsApp Integration:** Pre-fills customer name, date, guest count, package, and total directly into WhatsApp chat.
- **Interactive Visiting Card Showcase:** Interactive toggle to view both Front and Back of the official visiting card.
- **Dedicated Catering Services:** Family functions, weddings & engagements, birthdays, housewarmings (Gruhapravesam), community poojas, and corporate events.

## 💻 Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom Indian Luxury Palette: Deep Leaf Green `#0D3522`, Subtle Gold `#B88E28`, Warm Cream `#FAF7F0`)
- **Icons:** Lucide React
- **Animations:** Canvas Confetti

## 🛠️ Local Development
